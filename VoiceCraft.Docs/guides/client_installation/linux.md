# การดาวน์โหลด

ไปที่หน้า [Latest Release](https://github.com/AvionBlock/VoiceCraft/releases/latest) แล้วดาวน์โหลดไฟล์ที่มีชื่อว่า `VoiceCraft.Linux.zip`

<!-- หากใช้ DocFX tab system คุณอาจต้องแนบกับ #tab/linux -->

คุณจะต้องดาวน์โหลดและติดตั้ง [Dotnet 9.0](https://dotnet.microsoft.com/en-us/download) ด้วย หากยังไม่ได้ติดตั้ง  
เพราะเป็นไดรเวอร์ที่จำเป็นต่อการใช้งานโปรแกรมนี้

<!-- Dotnet 9.0 = .NET Runtime 9.0 ที่รองรับแอป Cross-platform -->

# การติดตั้งและเปิดใช้งาน

ไปยังโฟลเดอร์ที่คุณดาวน์โหลดไฟล์ `VoiceCraft.Linux.zip` แล้วทำการแตกไฟล์  
เมื่อแตกไฟล์เรียบร้อยแล้ว ให้เข้าไปในโฟลเดอร์ที่ได้จากการแตกไฟล์นั้น แล้วเปิดไฟล์ `VoiceCraft.Linux`

<!-- ถ้าใช้ terminal ได้ อาจเพิ่มตัวเลือก CLI ด้วย เช่น chmod +x แล้ว ./VoiceCraft.Linux -->
